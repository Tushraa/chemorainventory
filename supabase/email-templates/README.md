# Sign-in emails (sent by Supabase Auth)

These are the Chemora-branded versions of the Supabase Auth emails (square header with the Chemora logo).
Paste each file into **Supabase dashboard > Authentication > Emails > Templates** (Source tab) and use the subject below.

| Template | File | Subject |
| --- | --- | --- |
| Confirm sign up | `confirm-signup.html` | `[Chemora] Confirm your email` |
| Invite user | `invite.html` | `[Chemora] You have been invited` |
| Magic link | `magic-link.html` | `[Chemora] Your sign-in link` |
| Change email address | `email-change.html` | `[Chemora] Confirm your new email address` |
| Reset password | `reset-password.html` | `[Chemora] Reset your password` |
| Reauthentication | `reauthentication.html` | `[Chemora] Your confirmation code` |

The logo is loaded from `https://app.chemora.art/email-logo.png`.
