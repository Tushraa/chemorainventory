            Inventory Tools

            Import from CSV

            Upload a CSV with one row per container (up to 500 rows). Required columns: name, container_size, unit (g, mg, kg, mL, L, mmol, mol, units, rxns, cu ft) and location, written as the full path, e.g. Cabinet A / Shelf 2 / Tray 1, (> also works as a separator), or a unique location name. Dates may be YYYY-MM-DD or DD/MM/YYYY. Each row gets its own generated barcode.

            Bulk Container Update

            1. Download the current containers as CSV. 2. Edit the values you want to change in a spreadsheet (do not change barcode). 3. Upload the file; the changes are shown before anything is saved. Editable columns: supplier, catalog_number, lot_number, purity, received_at, expires_at, notes, remaining_amount.
